# my-c-project

If you wish to install Git on a user scope, run `install_git.bat` which can be found upon cloning the repository.

Additionally, download `winlibs-x86_64-posix-seh-gcc-...-mingw-w64ucrt-...-r?.zip` into `bin` from https://winlibs.com
Keep in mind - The in ... The file name is replaced with the corresponding supported version or version of your choice.
I used `winlibs-x86_64-posix-seh-gcc-16.2.0-mingw-w64ucrt-14.0.0-r2.zip`

for the configuration settings pointing to the GCC compiler and GDB debugger to function correctly and
for header files to function correctly.
